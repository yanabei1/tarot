# 无妄塔罗 · 在线塔罗占卜

单页、纯前端、完全离线的塔罗牌占卜工具。内置 **Rider-Waite 韦特体系全 78 张牌**（中文牌名 + 正逆位牌意 + 经典牌图）。

打开网址即可使用，无需安装、无需注册、不上传任何数据。

## 🌐 在线使用（GitHub Pages）

本仓库开启 Pages 后，访问：

```
https://<你的用户名>.github.io/tarot/
```

> 手机电脑都能打开，建议在手机浏览器「添加到主屏幕」，用起来和 App 一样。

### 首次开启 Pages 的步骤

1. 把本目录所有文件（含 `cards/` 目录和隐藏文件 `.nojekyll`）上传到仓库 `tarot`。
   - 网页端拖拽可上传 `index.html`、`README.md`、`cards/`；
   - `.nojekyll` 是隐藏文件，建议用 GitHub Desktop 或命令行补上（漏了通常也能正常访问）。
2. 进入仓库 **Settings → Pages**。
3. **Source** 选 `Deploy from a branch`，**Branch** 选 `main` + 目录 `/ (root)`，点 **Save**。
4. 等 1~2 分钟，刷新该页面即可看到网址。

### 目录结构

```
index.html      主程序（约 70 KB，牌图按需从 cards/ 加载）
cards/          78 张牌图（原生 250px，每张约 30 KB）
README.md       本说明
.nojekyll       跳过 Jekyll 处理
```

牌图拆分后的好处：首页体积从 5.7 MB 降到几十 KB，牌图并行下载并会被浏览器缓存，**第二次打开几乎瞬时**。

## ✨ 功能

- **6 种牌阵**：一张牌、三张牌（过去·现在·未来）、无牌阵三张、二选一、三选一、我以为·实际上
- **两种抽取方式**：随机抽取，或亲手从 78 张数字牌堆中点选
- **正逆位**：每张牌独立 50% 概率逆位，牌面标签与牌意同步显示
- **逐张翻牌**：点击牌面翻开 / 合上，点牌名查看完整牌意
- **自动保存**：抽牌即存入本机记录，可写解读笔记、随时回看与编辑
- **一键复制给 AI**：把本次占卜转成自然语言提示词，粘贴给 DeepSeek 等 AI 辅助解牌
- **牌库速查**：78 张牌按大阿卡纳 / 四花色筛选，支持关键词搜索
- **导出 / 导入**：记录可导出 JSON 或文本备份，也可导入合并
- **回到顶部**：长页面下右下角一键回顶

## 🔒 数据与隐私

- 所有记录**只保存在你自己的浏览器里**（localStorage 为主，IndexedDB 自动兜底），不上传服务器、无统计埋点。
- 若浏览器禁用了 localStorage（无痕模式、开启跨站跟踪防护等），程序会自动改用 IndexedDB 保存；两者都不可用时会在页面上给出明确警告。
- 换设备或换浏览器不会自动同步，请用「记录 → 导出 JSON」备份。

## 📱 兼容性

Chrome / Edge / Safari / Firefox 及主流手机浏览器均可。

## 🤖 AI 辅助解牌

页面只在**你主动点击**「复制此次占卜结果到其他AI - 辅助解牌」时，把问题、时间、牌阵与牌面（含正逆位）拼成文本放进剪贴板；随后可选择跳转 DeepSeek 网页版粘贴解读。除此之外不发送任何数据。

## 🖼️ 牌面版权

牌面为 1909 年公开出版的经典 Rider-Waite 塔罗（Pamela Colman Smith 绘制），原始图案在多数地区已进入公有领域；彩色版本及「Rider-Waite」名称的商标权益归各自权利人所有。

本页与配套程序**仅供个人学习与分享使用，请勿用于商业用途**。

## ⚠️ 占卜须知

1. 请不要在看到单张牌呈负面或逆位状态时，就根据简略牌意片面理解其整体状态；如果目前无法准确分析牌与牌之间的关系与结构，请寻求 AI 辅助或专业人士的帮助。
2. 牌对于未来的预测与推演，可能仅基于当下已经存在的因素；对未来的理解和态度不同，可能会让事情的发展与结果出现变化。请积极地面对牌的建议，而非将其奉为神谕。
3. 无论是对牌面的理解，还是基于牌对自身做出调整，都需要平静、精进而不失客观的内心。因此在看牌过程中，守护自身的内在安宁是一要务。
